# Our Blooms 🌸

A simple Flower Store project — named after my last name "Ward"
Built with React to practice API integration, data fetching, and project architecture.

## Tech Stack
- React
- Vite
- Tailwind CSS
- Pexels API

## Features
- **Home Page** — Introduction to "Our Blooms" (static images)
- **About Page** — Who we are & our story (static images)
- **Gallery Page** — Flower images fetched dynamically from **Pexels API**

## Project Structure

src/
├── assets/       # Static images (Home, About)
├── LayOut/       # Navbar, Footer, Layout wrapper
├── Pages/        # Home, About, Gallery
├── service/      # API calls (Pexels)
└── Style/        # CSS files


## What I'm Practicing
- Fetching data from a real external API (Pexels)
- Structuring a React project with reusable layout components
- Styling with Tailwind CSS
- Separating concerns (Pages / Layout / Services / Styles)
